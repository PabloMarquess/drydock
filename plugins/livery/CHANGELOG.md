# Changelog

## 0.1.1

### Fixed

- A reply or tool row with a wide table no longer grows past the screen and gets cut off on the right.

## 0.1.0

### Added

- A conversation theme for the desktop app: a tinted reply with an accent strip, a blue prompt, code cards and tool rows colored by kind.
- Palettes manteiga (default), areia, argila, gelo, cinza and plain; `/livery <palette>`, `/livery on`, `/livery off` and `/livery preview`.
